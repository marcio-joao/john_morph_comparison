# Data and code for: Phenotypic similarity in insular disconnected populations
Authors: Marcio João, Gustavo Mori, and Marcelo Pinheiro

# Description

This repository contains the data and scripts used to perform morphometric comparisons among Brazilian oceanic island populations of the endangered land crab *Johngarthia lagostoma*. The outcomes of this study are reported in the article:

**Isolation without divergence: comparing oceanic island populations of the land crab Johngarthia lagostoma**  
    https://doi.org/10.1093/biolinnean/blag021

---

# Repository structure

- `data/raw/linear-data` → raw data for linear morphometric analyses
- `data/raw/..._all` → raw landmark data for each body region (carapace, abdomen, and chela)
- `data/classifier/..._classifier` → metadata (id, island, morph) for geometric morphometric analysis
- `script` → R script used for geometric morphometric analysis applying *geomorph* package v. 4.0.10
